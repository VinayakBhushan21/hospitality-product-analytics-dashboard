# `# Project Brief — Hospitality Product Analytics Dashboard` 

# `## Objective` 

```
Analyse hotel booking data to understand what drives occupancy, cancellations,
and revenue across hotel types, seasons, and customer segments — and package the
findings into an interactive dashboard that a hotel operations or revenue
management team could act on.
```

# `## Data Source` 

```
Kaggle "Hotel Booking Demand" dataset
```

```
(https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand) — publicly
available with 119,000 booking records from two hotels (a City Hotel and a
Resort Hotel), covering bookings from 2015 to 2017. The fields include arrival
date, lead time, length of stay, country of origin, market segment, cancellation
status, and average daily rate (ADR).
```

# `## Deliverables` 

- `Cleaned, analysis-ready dataset` 

- `SQL queries answering key business questions (seasonality, cancellation drivers, revenue by segment, geographic demand)` 

- `Interactive Power BI dashboard with filters by year and hotel type` 

- `Short written summary of key findings and one actionable recommendation` 

# `## Timeline` 

- `Week 1: Source and clean data` 

- `Week 2: Run SQL analysis, identify key trends` 

- `Week 3: Build and format the Power BI dashboard` 

- `Week 4: Write up findings summary, finalize repo, publish` 

# `## Out of Scope` 

```
This is a descriptive analytics project — it is explaining what happened in the
data. It does not predict/forecast future events. No machine learning or future-
demand prediction is included.
```
